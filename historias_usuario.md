INSALUD

Historias de usuario

HU-01. Registrar cliente

Como funcionario de INSALUD S.A.S,
quiero registrar el nombre, la cédula, los síntomas y la dirección del cliente,
para guardar sus datos y gestionar su servicio médico domiciliario.

HU-02. Seleccionar plan

Como funcionario de INSALUD S.A.S,
quiero seleccionar el plan Básico (PB) o Preferencial (PP),
para calcular el valor mensual correspondiente.

HU-03. Registrar personas cubiertas

Como funcionario de INSALUD S.A.S ,
quiero indicar la cantidad de personas cubiertas por el plan,
para calcular el valor mensual total.

HU-04. Calcular valor mensual

Como funcionario de INSALUD S.A.S,
quiero calcular el costo mensual según el plan y la cantidad de personas cubiertas,
para conocer el valor que debe pagar el cliente.

HU-05. Aplicar descuento

Como funcionario de INSALUD S.A.S,
quiero aplicar el descuento del 12,5 % cuando los síntomas correspondan a gripa o alergia,
para calcular el valor mensual con el descuento correspondiente.

HU-06. Guardar información

Como funcionario de INSALUD S.A.S ,
quiero guardar la información del cliente y su facturación en un archivo TXT,
para conservar un respaldo de los datos registrados.

HU-07. Consultar información

Como funcionario de INSALUD S.A.S,
quiero visualizar los datos del cliente y su facturación,
para verificar el plan, las personas cubiertas, el descuento y el valor final.

HU-08. Atender varios clientes

Como funcionario de INSALUD S.A.S,
quiero registrar y procesar varios clientes consecutivamente,
para utilizar el sistema con diferentes usuarios sin tener que reiniciarlo.

HU-09. Finalizar factura actual

Como funcionario de INSALUD S.A.S,
quiero finalizar la factura actual cuando el médico escriba la palabra medicamento,
para terminar la atención de ese cliente y continuar con el siguiente.

HU-10. Salir del sistema

Como funcionario de INSALUD,
quiero seleccionar la opción de salida del menú,
para finalizar el uso del sistema de manera controlada.
